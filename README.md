# ⚡ LUFFYX – AI-Powered Virtual Assistant

LUFFYX is a modern full-stack AI assistant built using **Flask**, **Groq API**, and **Tavily API** with a cinematic UI inspired by intelligent conversational platforms.

It supports real-time conversations, live internet search, authentication, persistent chat history, voice input, and file uploads.

---

# 🚀 Features

✨ Real-time AI Conversations  
🌐 Live Web Search using Tavily API  
🧠 Context-Aware Follow-up Responses  
🎤 Voice Input Support  
📂 File Upload Support  
🔐 Login & Signup Authentication  
👤 Guest Mode Access  
💾 Persistent Chat History  
📜 Markdown Rendering  
⚡ Modern Responsive UI
